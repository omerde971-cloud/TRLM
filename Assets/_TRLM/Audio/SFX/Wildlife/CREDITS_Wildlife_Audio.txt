HOW TO REPLACE PLACEHOLDER FILES
=================================

Method 1 - Web Browser (Easiest):
  1. Go to https://freesound.org/search/
  2. Search for sound (e.g., "deer bleat")
  3. Add filter: License = "Creative Commons 0"
  4. Click on desired sound
  5. Click "Download" button
  6. Rename downloaded file to match placeholder name
  7. Replace placeholder file in scratchpad/audio/ directory

Method 2 - Direct URL Download:
  1. Find Freesound.org sound page URL
  2. Extract preview URL from page HTML
  3. Use PowerShell: 
     Invoke-WebRequest -Uri [preview_url] -OutFile [filename].mp3
  4. Verify file is >20KB and valid MP3
  5. Replace placeholder

Method 3 - Alternative Sources:
  - OpenGameArt.org (filter CC0)
  - Zapsplat.com (free license)
  - Pixabay Sound Effects (free license)
  - Kenney.nl audio packs (CC0)

Verify downloaded files:
  - Minimum size: 20 KB
  - Format: MP3 or OGG Vorbis
  - Should start with: ID3 tag or 0xFFFB (MP3 sync)
  - NOT HTML error page
